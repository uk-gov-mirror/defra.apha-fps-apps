User clicks Trigger │ ▼ PACT API (HTTP 202) │ ├─ writes fps.job_queue row as Initiated └─ dispatches worker event │ ▼ (UI polls /status?jobExecutionId=...) fps.job_queue lifecycle: Initiated ──▶ Running ──▶ Completed ✅ └──▶ Failed ❌ └──▶ Cancelled ✅ DB Table: fps.job_queue ├─ job_execution_id (UUID correlation key) ├─ job_name ├─ current_state (Initiated | Running | Completed | Failed | Cancelled) ├─ started_at ├─ completed_at ├─ requested_by └─ error_message
